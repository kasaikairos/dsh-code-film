# 在工具环境直接生成画面资产

使用 python tools/construct.py 项目/输入.json --out 项目/输出文件。仅需 Python 标准库，宿主容器可直接执行。Windows 包也可用 film.cmd construct。程序输出保存在项目目录，模型只读短摘要。若可访问的宿主已有浏览器与编码工具，正式导出也优先放在那里。

3D 用 kind=panel。size=[宽、高、厚]，pos=[中心x,y,z]，openings=[[从左下角起算的x,y,宽,高],…]，mat 使用 space 材质格式。构造沿 X/Y 的有厚度平板，将所有开口从实体中扣除；交叠孔按并集处理。把输出 objects 加到实际场景，可在镜头中观察孔深和穿过开口的物体。该构造适用于墙、隔板、格栅及器物外壳，非矩形开口需另建轮廓。

2D 用 kind=pigment。size=[宽,高]，palette 为由上至下的 6 位十六进制颜色，flow=[主要笔向x,y]，warp 为笔向变化（默认 .35），可传 seed、strokes=[粗,中,细]、clip（归一化多边形顶点）。输出 SVG 作为物体局部坐标画层。每个形体自行确定笔向、层次、取景及遮挡，程序可批量铺笔；水面、织物或植被可使用不同笔向。按动作变换整层；需要独立起伏的区域分别成层。复用画层时可在项目里一次栅格化至交付所需像素密度。

需要旋转体真实轮廓时用 kind=lathe。profile 是从下往上的 [半径,高度] 序列，封闭端可让首尾半径为 0。用轮廓描述杯口、接缝、螺帽台阶等形状，corner 为可选的轮廓倒圆尺度。radiusPx 用最近机位、最终分辨率下估计的最大像素半径，errorPx 是轮廓允许的弦高误差（默认 0.4 像素）。脚本据此选 12–192 个周向分段，并报告达到的估计误差。把 objects 放到原场景并用掠射光检查轮廓与高光。这个工具一次建模，适合轴对称部分；真实纹理、非轴对称零件和受光关系按实际镜头处理。

植被用 kind=plant。填 habit=tree 或 grass、height、spread、pos（根部世界坐标）、seed 和 density（叶片数）。palette 是叶色数组，树可给 bark 材质。程序从分叉生长枝条，把叶片接到枝梢或地表；叶片批量绘制，并参与遮挡。需要叶片随同一阵风弯曲时，可给 wind={"direction":[风向x,风向z],"strength":0.16}。根部固定，位移随叶长增加。粗枝保持稳定。物种辨识和英雄近景仍需要按实际参考定义轮廓与叶形。

建筑立面用 kind=facade。填 size=[宽,高,墙厚]、pos、mat、frameMat、paneMat 和 windows。每窗 opening=[离左边,离底边,宽,高]，可指定 inset（从墙外表面到窗框中心）、frame（框宽）及窗材质。实墙扣除开口，窗框和窗台的厚度会在侧光下形成投影。朝向约定与 panel 一致，外立面朝局部 +Z。可用透明 paneMat 配合自行建模的室内。

将构造写入镜头直接用 film.cmd construct 结构.json --scene 原镜头.json --out 新镜头.json。程序在磁盘中合并几何，模型只收摘要。先用关键镜头一帧检查可见轮廓、接缝和材质，再按取景增加局部细节。
