模型负责确定题目希望观众感受到的动作，工具负责用可复查的数值挑战这个判断。先用一句话描述运动中应保持的关系、应发生的相对变化及其时段。刚体、柔性、刻意定格、剪切换镜可有不同约束；只选与本镜意图相符的检查。尺度和容差由当前镜头的物体大小、运动时间或可见像素推定。

让镜头渲染和测试共用同一份姿态函数。写一个可在 Node 导入的 mjs 薄适配层，导出 poseAt(t)；返回最终变换后同一坐标系的点，如 {a:[x,y], b:[x,y]}。采样使用成片帧率、秒数和连续镜头范围。另导出 motionSpec={fps:60,frames:120,checks:[...]}。每条检查填 name、kind、point、limit，可填 interval:[起秒,止秒]。attachment 再填 relative_to，测两接触点最大允许距离；speed 测点的最大允许速度（坐标单位/秒）；relative_travel 再填 relative_to，测两点的相对位移向量从区间起点起至少应改变多少。后一项适用于预期有独立响应的部分。适配层引用真实场景求解逻辑，避免重新写一套示范动作。

运行 film.cmd motion_audit 工程/shot.motion.mjs。输出每条检查的峰值与帧号；退出码 1 表示至少一项未达预期。失败时用报告定位姿态、约束或时间函数的来源，修改共用的生成代码，用相同条件复测；改变驱动速度、目标位置或作用方向再测一次。最后按实际镜头审看事件前后：关节在机位中是否被遮掉，衣料或肢体是否呈现需要的轻重与先后。足够的相对位移只能证实有变化，不能单独给表演打分。

动作生成工具：film.cmd motion_kit 工程/motion-kit.mjs，把可独立运行的 ES 模块部署到项目。模型写清触发时刻、受影响部位、延迟反应和结果。travel(t,start,duration) 给零起止速度及加速度的 0–1 行程；recoil(t,at,decay,hz,amplitude) 给事件后的衰减摆动；reach2D(origin,target,upper,lower,bend) 返回两段连杆的 joint、end 和目标差 gap。给定 [x,y]，bend 为 +1 或 -1。接触前后的道具用同一个事件时刻，约束期内由接点推导位姿。柔性摆动或布料可按部位给不同延迟。函数按绝对秒数求值，跳帧预览与正式渲染可复现。不要为静谧的镜头强行加表演。

查假动作：motion_audit 新增 intrinsic_travel。填 anchors（至少两个同尺度的固定参考点名），point 与 limit。它测量部位到参考点的距离向量，用前两参考点间距做归一化。画面或整个人物平移、旋转、等比缩放时，归一化距离保持不变。用稳定的躯干或场景地标作为参考；3D 首选同一世界坐标系，透视图上深度变化可能影响结果。它能检出预期的局部变化是否存在；速度、受力和观感需核对具体动作。半秒到数秒的原帧率片段优先于静帧验证。

同一部位先划时间区间：无作用力或正在等、接触锁定、主动行程、反应或回稳。该静止用 kind=hold，interval 指明时段，limit 为从起点允许的最大漂移。有 anchors 时使用归一化的局部距离签名；省略时直接测世界坐标。接触仍用 attachment；必须发生的局部变化用 intrinsic_travel。不同部位的启动与回稳根据驱动力先后决定。避免给静物强加循环摆动。

motionTrack([{t:0,value:0},{t:1,value:0},{t:2,value:.5},{t:3,value:1}]) 可生成位置、角度或关节参数曲线。等值段保持静止；连续同向的中间关键点保有速度；要落定时用 rest:true。它保留各段单调性，不能替代接触约束。多维量可各用一条曲线，并核对实际路径与遮挡。

同一个可追踪的形体从一场交到下一场时，可用 handoff(前段路径,后段路径,开始秒,时长) 返回共用的状态函数。两条路径以绝对时间、同一坐标系求值，交接段在端点保留对应路径的速度与加速度。它可以连续传递主体位置、形状控制点或相机目标。角度先解包跨周差，旋转另用四元数。把算出的状态交给遮挡、光影和相机。有意硬切时用形状、运动方向或声音接力。正式输出前静音看切点前后的原速短段，再按 motion_audit 检查主体与固定参照物的相对运动。

有门框、前景遮挡、光照边界时，先选观众可以跟踪的轮廓。用 revealTrack(start,duration,[min,max],feather) 求移动边缘的位置，实际场景坐标是 field。着色器用 1 - smoothstep(edge - feather,edge + feather,field) 给入场层权重，可将同一权重用于对应材质和反光。field 限在 min 至 max。相邻段的主体继续共用运动轨迹，静物保持静止。位置衔接用 handoff；运动起势和跨段速度突跳用 motion_audit 的 velocity_jump，limit 是相邻帧速度向量差的上限，可给 relative_to 抵消共用位移。先根据物体尺度、拍摄速度和允许的加速度设 limit，然后在原速接缝片确认。

主动动作先写可见的驱动力。衣摆、细枝、悬挂物等可共用 followThrough(driver,{start,end,delay,frequency})。输入是实际运动的标量时间函数，返回较晚响应、逐渐追上并回稳的轨迹。start 取驱动前，end 给足回稳时间；锚点与硬接触由原始约束控制。求解只在加载场景时运行。把该轨迹同时交给实际渲染与 motion_audit 检验。
动作途中想排查只有镜头在动时，用 kind=activity，填活动时间 interval、speedFloor（每秒位移下限）、limit（有效帧比例 0–1）和可选 relative_to。先用静止场景参照或局部关节点抵消整体位移。停顿和定格的时间用 hold；比例由该动作所需的可读跨度决定。
